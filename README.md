# Train Ticket Booking System in C++

## About the Project
A console-based Train Ticket Booking System developed using C++ and Object-Oriented Programming concepts.

## Features
- View available trains
- Book train tickets
- Generate unique PNR numbers
- Check seat availability
- View ticket details
- Cancel reservations
- Store booking records using file handling

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling
- Standard Template Library (STL)

## How to Run
1. Download the C++ source code.
2. Open it in VS Code or Code::Blocks.
3. Compile using a C++11-compatible compiler.
4. Run the application.
5. Select an option from the menu.
